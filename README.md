### 5. Zero Trust Network Access (ZTNA) Simple Simulation (KDIN) 🔐
Proyek akhir mata kuliah Keamanan Data dan Informasi berupa simulasi lingkungan Zero Trust Network Access. Akses dikontrol berlapis lewat mutual TLS, RBAC berbasis JWT, dan penegakan kebijakan terpusat, lengkap dengan skenario simulasi serangan.

- **Jenis proyek:** Kelompok
- **Teknologi:** Docker, Nginx (OpenResty), Open Policy Agent, Keycloak, OpenZiti, Flask

### 6. Image Enhancement Dental X-Ray (Pengolahan Citra Digital) 🦷
Proyek akhir mata kuliah Pengolahan Citra Digital yang meningkatkan kualitas citra Dental X-Ray. Gaussian Filter digunakan untuk mengurangi noise, lalu Histogram Equalization untuk meningkatkan kontras agar detail citra lebih jelas.

- **Jenis proyek:** Kelompok
- **Teknologi:** Python, Gaussian Filter, Histogram Equalization
- **Repository:** [Kelompok-4-TIA-PCD-Project-Akhir-Image-Enhancement](https://github.com/006mareta/Kelompok-4-TIA-PCD-Project-Akhir-Image-Enhancement)

## 🔬 Pengalaman Riset

### Mahasiswa Riset, CAMEL Lab, Universitas Negeri Surabaya (Agustus 2026 – sekarang)
Saya terlibat sebagai mahasiswa riset di **CAMEL Lab** Teknik Informatika UNESA di bawah bimbingan **Ervin Yohannes, S.Kom., M.Kom.**

**Fokus riset:** Implementasi Deep Learning untuk *Image Deraining* pada citra hujan guna meningkatkan kualitas dan visibilitas citra.

- Mempelajari pendekatan deep learning untuk menghilangkan efek hujan (rain streak) dari citra
- Melakukan studi literatur, eksperimen, serta evaluasi kualitas citra hasil pemulihan
- Mengasah kemampuan penelitian ilmiah: perancangan eksperimen, analisis hasil, dan penulisan ilmiah

> 🔒 **Catatan:** Riset ini masih berjalan dan hasilnya belum dipublikasikan. Karena itu, detail metode, data, kode, dan hasil belum dapat saya tampilkan di profil ini. Informasi lebih lanjut akan saya tambahkan setelah publikasi diizinkan oleh tim riset.
